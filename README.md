# 合约交易计算器 · 收益 & 以损定仓

一个**纯前端、零依赖、可离线**的合约交易辅助工具：把「收益计算器」与「以损定仓计算器」合二为一，输入即算，专为手机浏览器优化（可"添加到主屏幕"当 App 用）。

> 在线体验：https://berthaxue.github.io/loss-size-calc/

---

## 功能一览

| 模块 | 作用 |
| --- | --- |
| 💰 收益计算器 | 输入开仓价 / 平仓价 / 开仓金额 / 杠杆，即时算出预期收益额、收益率、占用保证金、价格涨跌幅、持仓数量 |
| 🛡️ 以损定仓计算器 | 输入开单价 / 止损价 / 最大可承受止损金额 / 手续费，反推可承受的仓位保证金、名义金额、手续费与止盈目标 |

- 支持**做多 / 做空**方向切换，止盈价按方向自动朝上 / 朝下计算
- 支持**杠杆**倍数
- 配色遵循**币圈习惯**：涨 / 盈 = 绿色，跌 / 亏 = 红色（与 A 股相反）
- 单文件 `index.html`，**无任何外部依赖**，断网也能用
- 内置 PWA / 移动端适配，可添加到手机主屏全屏使用

## 使用说明

### 1. 收益计算器

**输入**
- 开仓价格（USDT）
- 平仓价格（USDT）
- 开仓金额（USDT）——即**仓位名义价值**（开仓数量 × 开仓价，统一以 USDT 计）
- 杠杆倍数（默认 1×）
- 方向：做多（买涨）/ 做空（买跌）

**输出**
- 预期收益额（USDT）
- 收益率（按占用保证金计）
- 占用保证金（USDT）
- 价格涨跌幅（%）
- 持仓数量（币，= 开仓金额 ÷ 开仓价）

**公式**

```
方向系数 d = 做多 取 +1，做空 取 -1
持仓数量   qty    = 开仓金额 ÷ 开仓价
预期收益额 pnl    = (平仓价 − 开仓价) × qty × d
占用保证金 margin = 开仓金额 ÷ 杠杆
收益率     roi    = pnl ÷ margin
价格涨跌幅 chg    = (平仓价 − 开仓价) ÷ 开仓价 × d × 100%
```

> 例：开仓金额 500 U、开仓价 60000、平仓 63000、1× 做多
> → 持仓 0.008333 BTC，收益额 +25.00 U，收益率 +5.00%。

### 2. 以损定仓计算器

> 本模块复刻自 [sn0wjin19/loss-size-calc](https://github.com/sn0wjin19/loss-size-calc)，并补充了**方向与杠杆**两项原工具没有的能力。

**输入**
- 开单价格（USDT）
- 止损价格（USDT）
- 最大承受止损金额（USDT）
- 手续费（单向 %，默认 0.05）
- 杠杆倍数（默认 1×）
- 账户总资金（可选，用于计算仓位占资金比例）
- 方向：做多 / 做空

**输出**
- 占用保证金（USDT）
- 仓位名义金额（USDT）
- 预计手续费（开 + 平，USDT）
- 止损幅度（%）
- 止盈目标价格：1 : 1 / 1.5 : 1 / 2 : 1 各一行
- （填了账户总资金时）该仓位占账户资金比例

**公式**

```
方向系数 d = 做多 取 +1，做空 取 -1
风险距离   diff   = |开单价 − 止损价|
仓位数量   qty    = 最大止损金额 ÷ diff          （内部计算用）
仓位名义金额 notional = qty × 开单价
占用保证金   margin = notional ÷ 杠杆
预计手续费   feeAmt = notional × 手续费率% × 2
止损幅度     stopPct = diff ÷ 开单价 × 100%
正向风险距离 r = (开单价 − 止损价) × d            （恒为正数）
止盈价：1:1   = 开单价 + r × 1
        1.5:1 = 开单价 + r × 1.5
        2:1   = 开单价 + r × 2
仓位占资金比 = 占用保证金 ÷ 账户总资金 × 100%
```

## 颜色与方向约定

| 含义 | 颜色 |
| --- | --- |
| 上涨 / 盈利 | 🟢 绿色 `#1faa59` |
| 下跌 / 亏损 | 🔴 红色 `#ff4d4f` |
| 做多（买涨）按钮 | 绿色 |
| 做空（买跌）按钮 | 红色 |

> 注：这是**币圈 / 国际惯例**。若你习惯 A 股的"红涨绿跌"，可在源码 `:root` 中交换 `--gain` 与 `--loss` 的取值。

## 在手机上随时使用

1. 用手机浏览器打开 https://berthaxue.github.io/loss-size-calc/
2. 点浏览器的「分享」→「**添加到主屏幕**」
3. 桌面会出现一个「合约计算器」图标，点开即**全屏 App**，且**断网也能用**

## 本地运行

无需任何构建步骤，直接双击 `index.html` 用浏览器打开即可。

```bash
# 或起一个本地静态服务（可选）
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 计算公式汇总

| 计算器 | 核心字段 | 公式 |
| --- | --- | --- |
| 收益 | 收益额 | `(平仓 − 开仓) × (开仓金额 ÷ 开仓价) × 方向` |
| 收益 | 保证金 | `开仓金额 ÷ 杠杆` |
| 收益 | 收益率 | `收益额 ÷ 保证金` |
| 以损定仓 | 仓位数量 | `最大止损额 ÷ \|开单价 − 止损价\|` |
| 以损定仓 | 保证金 | `仓位数量 × 开单价 ÷ 杠杆` |
| 以损定仓 | 手续费 | `名义金额 × 手续费率% × 2` |
| 以损定仓 | 止盈价 | `开单价 + (开单价 − 止损价) × 方向 × 倍数` |
